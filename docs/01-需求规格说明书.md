# 01 - 需求规格说明书

## 1. 项目概述

**项目名称**：treesize - 磁盘占用分析工具

**项目定位**：基于 Rust 技术栈的磁盘空间分析工具，集成 WizTree、WinDirStat、ncdu、TreeSize Free、Disk Savvy、WinTrim 等工具的核心优势，提供树形目录展示、Treemap 可视化、多维度报表、文件分类统计、重复文件扫描等功能，支持 CLI 和 GUI 双模式运行，最终打包为单个可执行文件。

## 2. 目标用户

- 系统管理员：监控服务器磁盘使用，定位异常占用
- 开发者：分析项目目录大小，清理构建产物
- 普通用户：查找磁盘空间占用大户，释放存储空间

## 3. 功能需求

### 3.1 核心功能

| 编号 | 功能 | 优先级 | 描述 |
|------|------|--------|------|
| F01 | 目录扫描 | P0 | 递归扫描指定路径，统计文件/目录大小、数量、修改时间 |
| F02 | 树形目录展示 | P0 | 以缩进树形结构展示目录层级，显示大小和占比 |
| F03 | Treemap 可视化 | P0 | 使用 Squarified Treemap 算法可视化磁盘占用分布 |
| F04 | Icicle/Flame Graph 可视化 | P1 | 使用 Icicle（自顶向下）和 Flame Graph（自底向上）布局算法，以矩形条带展示磁盘占用层级分布，支持 SVG 输出 |
| F05 | 多维度报表 | P0 | 支持 Tree/JSON/CSV/HTML/SVG 格式输出，含 TopN 排序 |
| F05 | 文件分类统计 | P1 | 按文件类型（视频/音频/图片/文档/源代码等）分类统计 |
| F06 | 重复文件扫描 | P1 | 基于 BLAKE3 哈希检测重复文件，计算浪费空间 |

### 3.2 扫描功能详细需求

| 编号 | 需求 | 描述 |
|------|------|------|
| F01-1 | 并行扫描 | 使用 rayon 并行遍历目录，充分利用多核 CPU |
| F01-2 | 进度回调 | 实时报告扫描进度（文件数、目录数、已扫描大小、当前路径） |
| F01-3 | 取消支持 | 支持中途取消扫描操作 |
| F01-4 | 排除过滤 | 支持排除指定目录名和扩展名 |
| F01-5 | 隐藏文件 | 支持跳过隐藏文件/目录（Windows 属性 + 点号前缀） |
| F01-6 | 最小大小过滤 | 支持设置最小文件大小阈值（应用于重复文件扫描，跳过大文件列表中的小文件） |
| F01-7 | 符号链接 | 可选是否跟随符号链接，默认不跟随 |
| F01-8 | 深度限制 | 支持设置最大扫描深度，防止过度递归 |
| F01-9 | 增量扫描 | 支持按文件修改时间增量扫描，仅扫描基准时间之后的文件 |
| F01-10 | 资源限制 | 支持限制最大文件数、扫描时间和内存使用 |

### 3.3 报表输出需求

| 编号 | 格式 | 描述 |
|------|------|------|
| F04-1 | Tree | 树形文本，支持深度限制和占比阈值过滤 |
| F04-2 | JSON | 结构化 JSON，包含完整目录树信息（可序列化） |
| F04-3 | CSV | 逗号分隔值，每行一个文件/目录，含路径/大小/类型/修改时间 |
| F04-4 | HTML | 自包含交互式 HTML 报表，含统计卡片、树形视图、TopN 表格、分类统计标签页 |
| F04-5 | SVG (Icicle) | Icicle 图 SVG，自顶向下布局，矩形宽度与文件大小成正比，颜色按分类区分 |
| F04-6 | SVG (Flame Graph) | Flame Graph SVG，自底向上布局，适合分析深层目录结构 |
| F04-7 | TopN | 显示占用最大的 N 个文件和 N 个目录 |
| F04-8 | 文件输出 | 支持将报表写入文件（--out-file） |
| F04-9 | All 格式 | 同时输出所有格式（tree/json/csv/html/icicle/flamegraph），自动扩展名处理 |

## 4. 非功能需求

| 编号 | 需求 | 目标 |
|------|------|------|
| NF01 | 性能 | 扫描 10 万文件目录耗时 < 5 秒（SSD） |
| NF02 | 内存 | 常规扫描内存占用 < 200MB，支持内存监控上限（默认 512MB） |
| NF03 | 单文件部署 | 编译为单个可执行文件，无外部动态依赖 |
| NF04 | 可执行文件大小 | Release 构建体积 < 6MB（不含内嵌字体），含字体约 10-15MB |
| NF05 | 跨平台 | Windows 优先，兼容 Linux/macOS |
| NF06 | 中文支持 | 界面和日志统一中文，GUI 内嵌开源中文字体 |
| NF07 | 日志管理 | 按日期轮转，保留 32 天，自动清理过期日志 |
| NF08 | 错误处理 | 统一中文错误信息，禁止泄露敏感信息 |
| NF09 | 并发安全 | 跨线程共享状态使用原子操作和互斥锁，防止数据竞争 |

## 5. 集成工具优势对照

| 工具 | 优势 | treesize 对应实现 |
|------|------|------------------|
| WizTree | 快速 MFT 扫描 | rayon 并行递归扫描 |
| WinDirStat | Squarified Treemap | Squarified Treemap 算法实现 |
| ncdu/diskonaut | CLI 交互式分析 | CLI 模式 + 多格式报表 |
| TreeSize Free | 多维度报表 + TopN | Tree/JSON/CSV 报表 + TopN 排序 |
| Disk Savvy | 文件分类统计 | 9 大类 + 扩展名分类统计 |
| WinTrim | 重复文件检测 | BLAKE3 哈希重复文件扫描 |

## 6. 约束条件

| 类别 | 约束 |
|------|------|
| 开发语言 | Rust 2021 edition，最低 rust-version 1.74 |
| CLI 框架 | clap 4.x（derive 风格） |
| GUI 框架 | egui 0.27 + eframe 0.27 |
| 架构模式 | DDD 四层架构：领域层 → 应用层 → 基础设施层 + 接口层 |
| 开发方法 | TDD 测试驱动开发（单元测试 + 集成测试） |
| 日志框架 | tracing + tracing-subscriber + tracing-appender（按日期轮转，保留 32 天） |

| 中文字体 | Noto Sans SC / Source Han Sans SC（SIL 开源协议） |
| 内存监控 | sysinfo 库监控系统内存使用 |
| 构建优化 | opt-level=3, lto=thin, strip=true, panic=abort |
