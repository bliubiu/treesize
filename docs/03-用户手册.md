# 03 - 用户手册

## 1. 安装

### 1.1 下载

从项目发布页下载对应平台的可执行文件：

- Windows: `treesize.exe`
- Linux: `treesize`
- macOS: `treesize`

### 1.2 从源码构建

**前置条件**：Rust 1.74+（推荐最新稳定版）

```bash
# 克隆仓库
git clone <repo-url>
cd treesize

# Debug 构建（开发用）
cargo build

# Release 构建（生产用）
cargo build --release
```

构建产物位于 `target/release/treesize.exe`（Windows）或 `target/release/treesize`（Linux/macOS）。

### 1.3 内嵌中文字体（可选）

默认情况下，GUI 模式会加载系统中文字体。如需内嵌开源字体（确保任何环境都能显示中文）：

1. 下载 [Noto Sans SC](https://fonts.google.com/noto/specimen/Noto+Sans+SC)（思源黑体，SIL 开源协议）
2. 将字体文件放入 `assets/NotoSansSC.ttf`
3. 重新编译：`cargo build --release`

构建脚本会自动检测字体文件并内嵌到二进制中。

## 2. 快速开始

### 2.1 CLI 模式

```bash
# 扫描当前目录（默认树形输出）
treesize .

# 扫描指定目录，限制深度
treesize --depth 2 C:\Users

# JSON 格式输出
treesize -o json /home/user

# CSV 格式输出，保存到文件
treesize -o csv --out-file report.csv /home/user

# 启用分类统计和重复文件扫描
treesize --classify --duplicates /home/user

# 排除 target 和 node_modules 目录
treesize --exclude-dir target --exclude-dir node_modules .

# 排除 .log 和 .tmp 扩展名
treesize --exclude-ext log --exclude-ext tmp .

# 同时输出所有格式（tree + json + csv + html + icicle + flamegraph）
treesize -o all --out-file report /home/user

# 查看 Top 50 大文件
treesize --top 50 /home/user

# 扫描大于 1MB 的重复文件
treesize --duplicates --dup-min-size 1048576 /path

# 生成 Icicle 图（自顶向下视图）
treesize -o icicle --out-file icicle.svg /home/user

# 生成 Flame Graph（自底向上视图）
treesize -o flamegraph --out-file flame.svg /home/user

# 调试模式运行（输出详细日志）
treesize --log-level debug /home/user
```

### 2.2 GUI 模式

```bash
# 启动图形界面（Windows 默认使用 MFT 引擎）
treesize --mode gui

# 启动图形界面并指定初始路径
treesize --mode gui C:\Users

# 指定扫描引擎
treesize --mode gui --engine mft   # NTFS MFT 直接读取（极速）
treesize --mode gui --engine fs    # 文件系统遍历（跨平台）
treesize --mode gui --engine usn   # USN Journal 增量扫描
```

GUI 操作：
1. 在顶部路径框输入要扫描的目录
2. 点击「扫描」按钮
3. 切换选项卡查看不同视图：概览 / 树形列表 / Treemap / 环形图 / TopN / 分类统计 / 重复文件 / 空间浪费 / 历史趋势 / 拖拽收集

## 3. 命令行参数

```
treesize [OPTIONS] [PATH]

参数：
  [PATH]                    待扫描的路径（默认当前目录）

选项：
      --mode <MODE>         运行模式：cli 或 gui [默认: cli]
      --engine <ENGINE>     扫描引擎：fs/mft/usn [默认: mft(Windows), fs(其他)]
  -o, --output <OUTPUT>     输出格式：tree/json/csv/html/icicle/flamegraph/all [默认: tree]
      --out-file <FILE>     输出文件路径（不指定则输出到 stdout）
  -d, --depth <DEPTH>       树形显示最大深度（0 = 不限）[默认: 10]
      --min-percent <PCT>   占比小于此百分比的节点折叠 [默认: 0]
      --top <N>             显示 TopN 大文件 [默认: 20]
      --classify            启用文件分类统计
      --duplicates          启用重复文件扫描
      --dup-min-size <SIZE> 重复文件最小大小（字节）[默认: 1024]
      --follow-links        跟随符号链接
      --no-hidden           不包含隐藏文件
      --min-size <SIZE>     最小文件大小过滤（字节）[默认: 0]
      --exclude-dir <NAME>  排除目录名（可多次指定）
      --exclude-ext <EXT>   排除扩展名（可多次指定）
      --log-level <LEVEL>   日志级别：debug/info/error [默认: info]
      --log-dir <DIR>       日志目录 [默认: logs]
  -h, --help                显示帮助信息
  -V, --version             显示版本号
```

### 扫描引擎说明

| 引擎 | 适用平台 | 说明 |
|------|---------|------|
| fs | 所有平台 | 文件系统遍历（jwalk 并行），兼容性好，速度适中 |
| mft | Windows | NTFS MFT 直接读取，速度比 fs 快 5-10 倍，需管理员权限 |
| usn | Windows | USN Journal 增量扫描，快速检测变更，需 Journal 启用 |

**自动降级**：Windows 默认使用 mft 引擎，若扫描失败（权限不足、非 NTFS 卷等），会自动降级到 fs 引擎重试。

### 4.7 SVG（Icicle / Flame Graph）

Icicle 图和 Flame Graph 以矩形条带可视化磁盘占用层级分布，每个矩形的宽度与文件/目录大小成正比。

| 模式 | 说明 | 适用场景 |
|------|------|---------|
| Icicle（自顶向下） | 根目录在顶部，子目录向下展开 | 快速定位大文件和目录 |
| Flame Graph（自底向上） | 叶子节点在底部，父目录向上堆叠 | 分析深层目录结构 |

输出规范：

- 格式：独立 SVG 文件
- 默认尺寸：1200px × (最大深度+1) × 32px
- 颜色：按 `FileCategory` 分类着色（视频=粉色，音频=青绿，图片=紫色 等）
- 交互：SVG 内置 `<title>` 悬停提示显示路径和大小
- 示例输出路径：`icicle.svg` / `flamegraph.svg`

```bash
# 生成 Icicle 图并保存
treesize -o icicle --out-file disk-usage.svg .

# 生成 Flame Graph 并保存
treesize -o flamegraph --out-file flame.svg .

# 直接查看 SVG（管道到 stdout）
treesize -o icicle . > icicle.svg
```

## 5. 输出规范

| 内容 | 输出目标 | 说明 |
|------|---------|------|
| 主报表（tree/json/csv/html/svg） | stdout / 文件 | 可通过管道重定向或 --out-file 指定 |
| 扫描摘要 | stderr | 文件数、大小、耗时 |
| TopN 报表 | stderr | 大文件/大目录排名 |
| 分类统计 | stderr | 文件类型分布 |
| 重复文件 | stderr | 重复文件分组 |
| 日志 | stderr + 文件 | 日志文件存储在 logs/ 目录 |

示例：将 JSON 报表保存到文件

```bash
# stdout 只有 JSON，摘要和日志在 stderr
treesize -o json /home/user > report.json
```

## 6. 日志系统

### 6.1 日志级别

| 级别 | 用途 |
|------|------|
| debug | 详细调试信息，包括每个文件的扫描过程 |
| info | 常规操作信息，如扫描开始/完成 |
| error | 错误信息，如扫描失败 |

### 6.2 日志文件

- 存储目录：`logs/`（可通过 `--log-dir` 指定）
- 文件命名：`treesize-YYYYMMDD.log`
- 轮转策略：每日一个文件
- 保留期限：32 天，自动清理过期日志

### 6.3 日志格式

```
[2024-01-15 10:30:00.123] [INFO] [1] [treesize::cli:42] - 扫描完成：文件 2554 个，总大小 1.20 GiB，耗时 52 ms
```

## 8. 常见问题

### Q: GUI 中文显示为方块？

A: 需要中文字体支持。两种解决方案：

1. **内嵌字体（推荐）**：下载 [Noto Sans SC](https://fonts.google.com/noto/specimen/Noto+Sans+SC)，放入 `assets/NotoSansSC.ttf`，重新编译
2. **系统字体**：确保系统安装了中文字体（Windows 默认有微软雅黑）

### Q: 扫描速度慢？

A: 尝试以下方法：
- **Windows 用户**：使用 `--engine mft` 启用 MFT 极速扫描（默认已启用）
- 使用 `--exclude-dir` 排除不需要的目录（如 `node_modules`、`.git`、`target`）
- 使用 `--min-size` 过滤小文件
- 使用 `--no-hidden` 跳过隐藏文件

### Q: MFT 扫描失败？

A: MFT 扫描需要管理员权限访问卷设备。如果失败：
- 尝试以管理员身份运行
- 或使用 `--engine fs` 回退到文件系统遍历
- 系统会自动降级到 fs 引擎重试

### Q: 如何只输出 JSON 到文件？

```bash
treesize -o json /path > output.json
```

### Q: 如何查找重复文件？

```bash
# 扫描大于 1MB 的重复文件
treesize --duplicates --dup-min-size 1048576 /path
```

### Q: 可执行文件太大？

A: Release 构建已启用 LTO 和 strip 优化，约 5-6 MB（不含内嵌字体）。含 Noto Sans SC 字体约 10-15 MB。
如需更小体积，可在 Cargo.toml 中调整：
- `opt-level = "z"` — 优化体积
- 移除不需要的 feature（如 `egui_extras`）
